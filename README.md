One satirical sentence about lawmakers who write the rules for AI, crypto and the internet — but cannot convert a file to PDF.

## The entry

`main.py` (Python 3.13) writes exactly one line to `/output/entry.txt`:

> The same committee that wrote 212 pages of AI law just emailed its staff a .docx asking if someone could turn it into a PDF.

The setup grants the lawmakers their authority — 212 pages of AI law — and the punch undercuts it with the one file they cannot convert. One sentence, 124 characters, no explanation needed.

## Running it

```sh
python3 main.py
cat /output/entry.txt
```
